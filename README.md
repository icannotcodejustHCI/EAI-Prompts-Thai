# UpToDate Expert AI · ตัวอย่างการใช้งานแยกตามสาขา

ฉบับภาษาไทยของ [เว็บไซต์ภาษาอังกฤษ](https://icannotcodejusthci.github.io/EAI-Prompts-Eng/) ประกอบด้วย 19 สาขา 71 กรณีศึกษา และ 119 คำถาม โดยคงโครงสร้าง การกรองตามสาขา ปุ่มคัดลอก ข้อมูลติดต่อ และการทำงานของต้นฉบับไว้

- หน้าหลัก: https://icannotcodejusthci.github.io/EAI-Prompts-Thai/
- หน้าดาวน์โหลดแอป: https://icannotcodejusthci.github.io/EAI-Prompts-Thai/mobile/

## เนื้อหาและขอบเขต

ข้อมูลกรณีศึกษาอยู่ใน `cases.json` คำแปลคงข้อเท็จจริง ตัวเลข หน่วย ขนาดยา ระยะเวลา ความไม่แน่นอน และข้อความปฏิเสธของต้นฉบับไว้ ไม่มีการเพิ่มคำตอบหรือคำแนะนำทางคลินิก ข้อสมมติหรือความไม่สอดคล้องของต้นฉบับไม่ได้ถูกแก้ไขโดยไม่แจ้ง

คำแปลผ่านการตรวจเทียบความครบถ้วนและความหมาย รวมถึงตรวจสอบคำศัพท์กับแหล่งข้อมูลทางการแพทย์ของไทย การตรวจนี้ไม่ใช่การรับรองโดยแพทย์ผู้ใช้ภาษาไทย ควรให้บุคลากรทางการแพทย์ผู้ใช้ภาษาไทยตรวจทานก่อนนำไปใช้ในการฝึกอบรมหรือการใช้งานทางคลินิก

## การแสดงผล

เอกสารกำหนดภาษาเป็น `th` และใช้ฟอนต์ Noto Sans Thai ที่จัดเก็บไว้ใน `fonts/` พร้อมใบอนุญาต SIL Open Font License เพื่อรองรับสระและวรรณยุกต์ไทย โดยไม่ต้องโหลดฟอนต์จากเว็บไซต์ภายนอก

โลโก้และ favicon คงตามต้นฉบับ ป้ายดาวน์โหลดใช้ไฟล์ภาษาไทยจาก Apple และ Google โดยไม่แก้ไขอาร์ตเวิร์ก ลิงก์ร้านค้าเป็นหน้าประเทศไทยของแอปเดียวกัน ตรวจสอบเมื่อ 5 พฤศจิกายน 2026:

- [App Store ประเทศไทย](https://apps.apple.com/th/app/uptodate-expert-ai/id6756627759?l=th) ผู้พัฒนา UpToDate, Inc.
- [Google Play ประเทศไทย](https://play.google.com/store/apps/details?id=com.uptodate.expertai&hl=th&gl=TH) ผู้พัฒนา Wolters Kluwer Health UpToDate

หน้าร้านภาษาไทยไม่ได้หมายความว่าแอปรองรับภาษาไทย การติดตั้งและสิทธิ์ใช้งานขึ้นอยู่กับบัญชี อุปกรณ์ ประเทศ และการสมัครสมาชิกของผู้ใช้ คำแนะนำการลงทะเบียนผ่านเครือข่ายของสถาบันคงตามต้นฉบับ

## ผู้ดูแลระบบ

เปิด **ผู้ดูแลระบบ** ที่ท้ายหน้าเพื่อเพิ่มกรณีศึกษา เพิ่มสาขา หรือจัดการรายการ กด **บันทึก (Commit)** เพื่อบันทึก `cases.json` ลงในที่เก็บโค้ด `icannotcodejustHCI/EAI-Prompts-Thai` บนสาขา `main` เท่านั้น ไม่เปลี่ยนเว็บไซต์ภาษาอังกฤษ ภาษาเกาหลี หรือภาษาญี่ปุ่น

ต้องใช้ GitHub fine-grained personal access token ที่จำกัดเฉพาะที่เก็บโค้ดนี้และมีสิทธิ์ **Contents: Read & Write** ป้อนเฉพาะในช่องรหัสผ่านบนหน้าเว็บ ไม่ใส่ในซอร์สโค้ด ไม่ส่งผ่านแชต และไม่เปิดเผยให้ผู้อื่น โทเค็นไม่ถูกจัดเก็บและจะถูกล้างเมื่อปิดหน้าต่างผู้ดูแลระบบ

ระบบเข้ารหัส UTF-8 รองรับข้อความภาษาไทย และป้องกันการบันทึกซ้ำขณะที่กำลังดำเนินการ การบันทึกที่ล้มเหลวจะไม่เพิ่มกรณีศึกษาซ้ำในสำเนาที่รอบันทึก

## แบ่งปันคำถามและข้อเสนอแนะ

ปุ่ม **แบ่งปันคำถาม** และ **ส่งข้อเสนอแนะ** เปิดร่างอีเมลในแอปอีเมลของผู้ใช้ผ่าน `mailto:` เท่านั้น ไม่ส่งอีเมลอัตโนมัติ ผู้รับยังเป็น `jiseong.kim@wolterskluwer.com` ตามต้นฉบับ โปรดไม่ใส่ข้อมูลที่สามารถระบุตัวผู้ป่วยได้

## การเผยแพร่และการทดสอบ

เผยแพร่ด้วย GitHub Pages จากสาขา `main` และโฟลเดอร์ราก สามารถแสดงตัวอย่างในเครื่องด้วยเว็บเซิร์ฟเวอร์สแตติก เช่น `python -m http.server 8000` แล้วเปิด `http://localhost:8000/` การเปิด `index.html` โดยตรงด้วย `file://` อาจโหลด `cases.json` ไม่ได้

ตรวจสอบความครบถ้วนของ 71 กรณีศึกษา 119 คำถาม และ 19 สาขา รวมทั้งโครงสร้าง JSON ไวยากรณ์ JavaScript ลิงก์ภายใน ฟอนต์ และการกำหนดเป้าหมายของผู้ดูแลระบบ ไม่มีการส่งอีเมลหรือใช้โทเค็นจริงในการทดสอบ
